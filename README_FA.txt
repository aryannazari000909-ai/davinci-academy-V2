# DaVinci Academy — نسخه 1.0.1

## انتشار در GitHub Pages
1. فایل‌های داخل این پوشه را در ریشه مخزن GitHub قرار دهید.
2. فایل‌های قدیمی `index.html`، `sw.js`، `manifest.json` و `icon.svg` را با نسخه‌های جدید جایگزین کنید.
3. دو فایل جدید `style.css` و `script.js` را نیز اضافه کنید.
4. Commit کنید و منتظر انتشار GitHub Pages بمانید.

## نکته مهم درباره اطلاعات قبلی
کلید LocalStorage نسخه قبلی (`davinci-academy-v1`) حفظ شده است؛ بنابراین پیشرفت ذخیره‌شده در همان مرورگر و همان دامنه باید باقی بماند. قبل از جایگزینی، از بخش «دریافت پشتیبان» یک فایل پشتیبان تهیه کنید.

## محتویات
- `index.html`: ساختار صفحه و رابط کاربری
- `style.css`: طراحی واکنش‌گرا و تم سینمایی
- `script.js`: منطق برنامه، ذخیره پیشرفت و پشتیبان‌گیری
- `manifest.json`: تنظیمات PWA
- `sw.js`: کش آفلاین با شناسه نسخه جدید
- `icon.svg`: آیکون برنامه

## توضیح
فهرست ۸۲ ویدیو در فایل اولیه فقط با شماره درس‌ها مشخص شده بود؛ در این نسخه نیز عنوان واقعی درس‌ها جعل نشده و شماره‌ها حفظ شده‌اند.
